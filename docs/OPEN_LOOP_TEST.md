# 两极对电机开环试转

本工程已加入电压开环 FOC 测试：用虚拟电角度做逆 Park 变换，再以公共模式注入实现 SVPWM。没有编码器、观测器、电流环或速度反馈，显示的 RPM 是指令值，不是实测速度。

## 当前 bench 实机配置（已实测可转）

- 相电压 `g_motor_phase_voltage_v = 2.0f`，目标 `g_motor_target_rpm = 90.0f`（2 极对 → 3Hz 电频率）。0.15V/30rpm 的旧默认扭矩不足，空载也推不动。
- 时序：20ms 预充 + 500ms 定位 + 2000ms 加速 + **15000ms 运行** + 1000ms 减速 ≈ **18.52s**。
- 母线允许 12–24V；相电压上限 2.0V；SVPWM 线性区限幅为 0.5×母线。
- 过流阈值 `MOTOR_CURRENT_TRIP_A = 1.5A`。
- 供电限流至少 1A（否则一拉电流母线跌到 12V 以下会触发欠压停机）。

### 已知硬件故障：W 相电流采样

本板 W 相采样的运放输出（U9.2 → R41 → PB12 / ADC1_IN11）只有约 0.093V，正常应约 1.62V（=VREF），所以上电电流零点自检判失败并锁死。临时对策是 `motor_test.c` 里的 `MOTOR_BENCH_RELAX_W_ZERO 1`，只放行 W 相这一路的零点窗口（稳定性/轨/过流检查仍有效）。

排查：量 U9.2 第 7 脚 / R41 / PB12 对地电压，应与 PB14、PB11 同为约 1.62V。按读数反推，最像 R40 或 R46 开路/虚焊（+INB 被 R38/R39 分压到 VREF×2/35≈0.094V）。修好后把 `MOTOR_BENCH_RELAX_W_ZERO` 改回 `0`。

## 原理图对应关系

| 电机相 | PWM 通道 | MCU 引脚 | EG2133 输入 |
| --- | --- | --- | --- |
| U | TIM1_CH3 | PA10 | HIN1 / LIN1# |
| V | TIM1_CH2 | PA9 | HIN2 / LIN2# |
| W | TIM1_CH1 | PA8 | HIN3 / LIN3# |

每相 HIN 和 LIN# 接在一起，EG2133 内部产生上下管互补和死区。因此不使用 TIM1_CHxN。三路输入全低时，三只下管导通，电机端子被短接制动；本板不能通过这三根线单独实现六只 MOS 全关的滑行停机。

PB15 / ADC2_IN15 读取母线电压，R37=100k、R45=10k，分压比 11。默认 VDDA=3.3V，需要用万用表检查显示的母线电压；如有偏差，修改 motor_test.c 中 ADC_VDDA_V。软件允许 12-24V，供电明显下跌即停机。原理图标注板卡供电 12-24V。

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| SW2 | PC15 | 正转测试 |
| SW3 | PC14 | 反转测试 |
| SW4 | PB10 | 停止 / 清除故障 / 清除使能 |

按键低有效，已开启内部上拉。启动按键有 30ms 消抖；停止按键直接检查。PC13 的 LED 测试时常亮，故障时闪烁。

## 首次测试条件

1. 先确认电源在 12-24V（例如 16V）、具有限流功能。母线电源限流设为 1A 以上，先不启动电机，确认板卡能稳定保持设定电压、没有进入 CC 限流。如空闲时已进入限流，先排查供电和板卡，不继续启动。
2. 电机参数暂未知。当前默认相电压 2.0V、目标 90rpm，空载一次短测试（约 18.5s）。若电压太低（如旧的 0.15V）扭矩不足会完全不转；不转时先停机记录读数。母线限流不能直接限制绕组环流，此参数也不能保证适用于所有未知电机。后续增加输出前，尽量测量电机线间电阻并扣除表笔电阻。
3. 电机可以空载、轴可自由转动；预期正转方向从哪一侧观察。
4. SWD 下载器接好 H4：1=3V3参考，2=PA13/SWDIO，3=PA14/SWCLK，4=AGND；供电方式避免两个 3.3V 电源互相顶接。

已将 ADC1 改成单端采样：U=PB14/IN5，V=PB11/IN14，W=PB12/IN11。上电保持轴静止，先等待模拟电路稳定 500ms，然后采集 128 组零点；偏置异常或波动过大会拒绝启动。校准通常在上电约 0.63s 后完成，但主循环调度可能延长这一时间，以 g_motor_current_ready=1 为准。

按 10mΩ 采样电阻、33k/2k=16.5 的信号增益换算电流，原理图标注的 17.5 对应运放噪声增益，不能直接作为该差分电路的信号增益。任一采样支路绝对值达到 1.5A、ADC 接近电源轨或电流采样超过 10ms 未更新，都会停止 PWM。电流故障锁存，排查后复位重新校准，不会把过流读数自动学习成新零点。

这仍没有电流闭环或硬件逐周期过流切断。低侧采样经过 1kΩ/100nF 滤波，软件异步读取的是滤波后的支路电流，不能当成绕组峰值；1.5A 阈值不等于保证绕组电流小于 1.5A。软件也无法阻止直通或极短的电流尖峰。软件停机采用下管短接制动，制动电流不受母线电源限流直接控制。上述措施降低初测风险，不能保证 MOS 永不损坏。

## Keil 调试操作

1. 打开 MDK-ARM/Mymotor.uvprojx，选择 Mymotor，编译并通过 SWD 下载更新后的固件。上电不会自动试转，g_motor_phase_voltage_v 初值为 2.0V，g_motor_arm 初值为 0。
2. 保持 MCU 运行，在 Watch 查看 g_motor_bus_voltage_v 并与万用表测量比较；检查驱动 +12V、3V3、VDDA 电源正常。必要时先不接电机，用示波器检查输出。
3. 等待 g_motor_current_ready=1，检查 g_motor_current_adc[0..2] 静止时约在 2048 附近、g_motor_shunt_a[0..2] 接近 0（注意本板 W 相采样硬件故障，见上文）。默认 g_motor_phase_voltage_v=2.0、g_motor_target_rpm=90。相电压表示旋转电压矢量峰值，单位 V，不是线电压 RMS。软件上限 2.0V；未知电机首次测试不要直接填上限。
4. 将 g_motor_arm 写成 1，再短按 SW2。也可以写 g_motor_command=1 正转，或 -1 反转。每次启动消耗一次 arm，修改参数只对下一次启动生效。
5. 测试依次执行：20ms 下管导通给自举充电、500ms 定位（前 200ms 电压爬升）、2s 加速、15s 运行、1s 减速，然后短接制动，总计约 18.52s。90rpm、两极对对应 3Hz 电频率。测试中若进入电源 CC、仅抖动或出现异常声响，按 SW4 停止并记录读数。
6. 随时按 SW4，或写 g_motor_command=2 停止。反向测试前等轴停稳，然后重新 arm=1 再按 SW3。运行中不会直接切换方向。

不要长时间暂停调试器让电机停在固定电压矢量上；CPU 暂停后软件保护和超时不能执行。观察 Live Watch 时保持程序运行。

g_motor_status 中可查看 state、fault、commanded_rpm、angle_rad、voltage_v 和 duty_u/v/w。故障码：0=无，1=参数错误，2=母线越界，3=ADC失败，4=母线采样超过50ms或电流采样超过10ms未更新，5=未arm，6=PWM时钟配置错误，7=电流监测未就绪，8=电流零点异常，9=电流ADC接近电源轨，10=支路电流超限。一般故障按停止清除；8/9/10 在电流监测模块中锁存，排查后需复位重新校准。

## 如何判断结果

- 空载平稳转动、正反测试方向相反：三相连接和驱动的基本试转通过；仍不能证明每根电机线的厂家 U/V/W 标签。
- 平稳转动但方向与约定相反：断电后交换任意两根电机相线，再试同一个方向指令。
- 只抖动、啸叫、不转或电流过大：先停止，记录母线电压、限流值、输出电压、故障码和波形。电压不足、加速过快、负载、缺相、驱动或焊接问题都可能造成同样现象，不能据此认定线序错误。
- 循环置换三根线只改变电角度参考；无传感器时通常不能区分这些排列。

当前 PWM 为 20kHz 边沿对齐，TIM1 重复计数器分频后以 1kHz 执行控制。没有更改原 HSI 16MHz 系统时钟；TIM1 在自定义模块中配置，CubeMX 尚未配置该外设。重新生成工程后，确认 foc_openloop.c、motor_test.c、motor_current.c 仍在 Keil 工程中，并避免 CubeMX 同时生成另一份 TIM1 配置。

## 软件验证与硬件验证的界限

tests/test_foc_openloop.c 在主机上运行实际的控制核心，覆盖 SVPWM 线电压重构、正反转、两极对角度积分、阶段时序、非法参数、母线故障和停机。tests/test_motor_current.c 覆盖电流零点校准、增益、三相正负超限、故障锁存、ADC饱和和不稳定零点。Keil 构建生成 AXF / HEX。软件验证无法确认焊接、实际采样增益、驱动波形、死区是否足够或电机是否已转动；这些仍需要实物测试。

主机测试命令（PowerShell，已安装 GCC）：

```powershell
gcc -std=c99 -Wall -Wextra -Werror -I Core/Inc Core/Src/foc_openloop.c tests/test_foc_openloop.c -lm -o tmp/test_foc_openloop.exe
./tmp/test_foc_openloop.exe
gcc -std=c99 -Wall -Wextra -Werror -I Core/Inc Core/Src/motor_current.c tests/test_motor_current.c -lm -o tmp/test_motor_current.exe
./tmp/test_motor_current.exe
```
